# ArelTS: A Typescript Relational Algebra

A relational algebra for typescript. Closely modeled after [`ActiveRecord`](https://rubygems.org/gems/activerecord)'s.

ArelTS doesn't care about validating that columns, tables, or the SQL it produces are _semantically_ accurate; it only cares to product _syntactically_ accurate statements.

To install dependencies:

```bash
bun install
```
